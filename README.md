# Milestone 1 – Project Initialization, Design Process & Core Setup

## Project
Sports Injury Risk Detection from Video

## Student
Potnuri Sravani

## Milestone Duration
Week 1 & Week 2

## Objective
The objective of Milestone 1 is to establish the core foundation of the Sports Injury Risk Detection platform, including system architecture, authentication, athlete profile management, UI planning, development environment setup, and dataset collection.

## Tasks Completed

- Defined project objectives and injury detection workflows.
- Designed system architecture and database structure.
- Created UI wireframes and workflow planning.
- Set up frontend and backend environments.
- Implemented authentication and role-based access control.
- Designed athlete profile management workflows.
- Identified sports biomechanics datasets.

## Datasets

- Human3.6M Dataset
- MPII Human Pose Dataset
- COCO Keypoints Dataset
- SportsPose Dataset
- FIFA Injury Dataset (Reference)

## Technologies

- Python
- FastAPI
- React.js
- PostgreSQL
- MongoDB
- Git & GitHub

## Outcome

Milestone 1 establishes the foundation required for the next stages of the project, including pose estimation, biomechanical analysis, injury prediction, and recommendation systems.
